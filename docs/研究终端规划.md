# 研究终端规划

> 产品主旨：多方法选股 → 观察队列 → 可持续性验证 → 复盘（**不下单**）。  
> 本文记录当前能力边界、已落地通道与后续规划，便于按优先级推进。

## 1. 目标闭环

```
选股通道（技术 / 事件 / 观点 / 资金 / 龙虎榜 / …）
        ↓ 一键进料
观察队列（observe / hold / reject）
        ↓ 工作台验证
可持续性评分 + 资金/龙虎/事件/观点摘要
        ↓
研究档案 / 复盘（不触发交易）
```

原则：

- 通道产出的是**候选**，不是买卖信号。
- 密钥只放服务端 `.env`，不进仓库、不回显到前端。
- 优先可解释、可缓存、可调度的规则聚合；LLM 仅用于解析/抽取，不作为榜单打分主路径。

## 2. 已落地（截至本文）

### 2.1 观察队列与工作台

| 能力 | 说明 |
|------|------|
| 观察队列 | `watch-candidates` 持久化；来源可叠加：`strategy` / `fusion` / `event` / `opinion` / `industry` / `fund` / `dragon` / `manual` |
| 工作台 | 迷你日 K、可持续性卡、资金流向、龙虎榜、相关事件、观点信号 |
| 复盘统计 | 按状态/来源汇总；支持改状态、移出队列 |
| 导航 | TopBar / 全市场 / 批量分析可跳转工作台或灌入选股种子 |

### 2.2 消息面

| 能力 | 说明 |
|------|------|
| 金十 MCP | 快讯 / 资讯 / 日历 / 报价；A 股相关优先入库 |
| 一级事件 | `market-events` 采集与落盘；交易时段定时采集 |
| 事件荐股 | 点名优先 + 行业代表（自选/观察优先）；宏观噪音不进榜 |
| 资讯页 | `NewsEventPanel`；可跳选股 / 进观察 |

### 2.3 观点面

| 能力 | 说明 |
|------|------|
| 博主同步 | 知乎 Cookie / 雪球 Cookie；本人内容优先 |
| 观点荐股 | 与事件通道同构；行业 claim 可生成板块代表 |
| 观点页 | 顶部共识条 → 观察 / 灌入选股 |

### 2.4 资金面（一期）

| 能力 | 说明 |
|------|------|
| 东财主力净流入 | 候选池日榜缓存；近 N 日合计 / 连续流入打分 |
| 资金荐股 | 选股页「资金驱动」；池空可手动刷新 |
| 调度 | 交易日约 15:40 后尝试日刷 |
| 已知问题 | 部分环境访问东财 `push2his` 不稳定（SSL/空响应）；失败保留旧缓存 |

### 2.5 龙虎榜（扶摇）

| 能力 | 说明 |
|------|------|
| 数据源 | 同花顺扶摇 REST：`/api/a-share/special-data/dragon-tiger-list` |
| 榜单类型 | `all` / `org`（机构）/ `hot_money`（游资） |
| 荐股 | 净买额为主指标；机构+游资双正加分；默认排除大跌 |
| 日期 | 扶摇缺省为「早于今天」的交易日；**收盘后刷新显式传当日**（已修复） |
| 调度 | 交易日约 16:20 后日刷 |
| 边界 | 这是上榜席位买卖，**不是**每日主力净流入序列；与资金通道互补 |

### 2.6 技术选股（既有 + 增强）

- 条件选股 / AI 解析 / 策略多选 / 融合 / 回测实验室仍可用。
- 可叠加「近 N 日须有一级事件」过滤。
- 选股进度可轮询展示。

## 4. 后续规划

### 4.1 资金面二期（优先于基本面深挖）

1. **资金流备用源**：在东财失败时切换代理 host / 备用供应商；或缩小池（仅自选+观察）保底刷新。  
2. **工作台资金卡增强**：标注缓存时间、失败原因；支持单票强制重拉。  
3. **资金 × 龙虎交叉**：同日净流入 + 上榜净买同时命中时提高观察优先级（规则加分，非 LLM）。  
4. **连续上榜 / 隔日回流**：多日龙虎榜缓存，识别反复上榜与机构持续净买。

### 4.2 基本面二期（半有 → 可筛选）

现状：已有 PE / 市值 / 双低等快照条件，缺独立「估值驱动」通道与更深财报字段。

建议分期：

| 阶段 | 内容 | 产出 |
|------|------|------|
| B1 | `minPb` / `maxPb` 条件 + 选股页「估值驱动」轻量通道（双低/低 PE+低 PB 等规则） | 可复用快照字段 |
| B2 | 工作台估值卡（PE/PB/市值分位，相对行业） | 观察阶段可读 |
| B3 | ROE / 营收增速等财报深度（需稳定财务源） | 后置，避免阻塞消息/资金 |

### 4.3 消息面质量

1. 主题词 → 申万行业映射继续校准，减少错配代表股。  
2. 监管类事件：仅**点名个股**硬否决；主题监管不误杀全板块。  
3. 金十与其它新闻源的去重、垃圾标题过滤持续维护。

### 4.4 体验与工程

1. 通道结果「全部加入观察」的批量上限与去重提示。  
2. 可持续性报告纳入龙虎/资金因子（可选权重）。  
3. 集成测试：扶摇 / 金十在无 Key 时返回 503，有 Key 时冒烟。  
4. 密钥轮换：聊天中出现过的 Key 应在控制台轮换，仅保留本机 `.env`。

## 5. 环境变量（服务端）

| 变量 | 用途 |
|------|------|
| `JIN10_MCP_TOKEN` / `JIN10_MCP_URL` | 金十快讯与日历 |
| `FUYAO_API_KEY` / `FUYAO_API_BASE` | 扶摇龙虎榜 |
| `ZHIHU_COOKIE` / `ZHIHU_ACCESS_SECRET` | 知乎观点同步 |
| `XUEQIU_COOKIE` | 雪球观点同步 |
| `DEEPSEEK_API_KEY` / `ANSPIRE_*` / `TICKFLOW_API_KEY` | 既有 AI / 行情 |

详见仓库根目录 `.env.example`。

## 6. 推荐推进顺序

1. 资金流备用与失败可观测性（稳住资金通道）  
2. 龙虎多日缓存 + 与资金交叉加分  
3. 基本面 B1（估值条件 / 轻量通道）  
4. 可持续性纳入资金与龙虎因子  
5. 基本面 B3（财报深度）视数据源成熟度再开
